## 数据处理策略

### 外键处理

由于备份数据中的 `user_question_banks` 表依赖 `users` 表（外键约束），而开发环境中没有对应的用户数据，因此：

1. **创建系统用户**: 创建了一个特殊的系统用户 `system_public` (ID=1)
2. **重新映射**: 将所有公共题库的 `user_id` 映射到系统用户
3. **ID 重新分配**: 题库和题目的 ID 重新生成，保持数据一致性

### 数据过滤

- **仅导入公共题库**: 通过 `is_public=true` 过滤
- **排除用户数据**: 不导入任何用户相关数据（用户表、答题记录、收藏、考试记录等）
- **保留题目完整性**: 保留题目的所有字段（内容、选项、答案、解析、标签、难度等）
