## CRITICAL 严重漏洞

### C-01: 密钥泄露到 Git 历史

**位置**: `.env`
**问题**: 以下敏感凭证已被提交到 Git 历史（commit cd76d88, 6316ea4）：

- `WECHAT_SECRET=714b6315c5e27cb2689c3c1d5bd54e2d`
- `DASHSCOPE_API_KEY=sk-9305b010e9be495b8407611f14394fd5`
- `SECRET_KEY=Saksk1234567890`

**影响**: 任何有仓库访问权限的人可获取所有密钥，伪造 JWT、调用第三方 API。
**修复**:
1. **立即轮换**所有暴露的密钥（微信 Secret、DashScope Key）
2. 使用 `git filter-branch` 或 BFG Repo-Cleaner 从历史中清除
3. 生成强 SECRET_KEY: `python -c "import secrets; print(secrets.token_urlsafe(32))"`

### C-02: 弱 SECRET_KEY

**位置**: `.env` / `app/core/config.py:25`
**问题**: `SECRET_KEY=Saksk1234567890` 仅 15 字符，可被暴力破解。
**影响**: JWT token 可被伪造，会话可被劫持。
**修复**: 使用至少 32 字节的随机密钥，并在生产配置中强制要求设置。

---

### C-03: 管理员 API 缺少认证装饰器

**位置**: `app/modules/admin/routes/api_components/users.py:35-37`
**问题**: 所有管理员 API 端点（`/admin/api/users/*`）缺少 `@admin_required` 装饰器。虽然 `app/__init__.py` 的 `before_request` 钩子有全局路径检查，但：

**影响**: 如果全局钩子被绕过，普通用户可执行管理员操作（切换权限、锁定用户等）。

## HIGH 高优先级漏洞

### H-01: XSS - 模板中使用 `|safe` 过滤器

**位置**:
- `app/modules/exam/templates/exam/exams_v2.html:499`
- `app/modules/exam/templates/exam/exams_v3.html:488-489`
- `app/modules/quiz/templates/quiz/partials/quiz/assets/js/_00_bootstrap.html:5,347`
- `app/modules/main/templates/main/mistakes/mistakes_detail.html:228`
- `app/modules/main/templates/main/favorites/favorites_detail.html:226`

**问题**: 使用 `|safe` 过滤器将数据注入 JavaScript，绕过自动转义。
```html
const SUBJECT_Q_TYPES = {{ subject_q_types_json|safe }};
```
**影响**: 如果 JSON 数据包含恶意脚本，将导致存储型 XSS。
**修复**: 使用 `|tojson` 过滤器替代 `|safe`。

---

### H-02: DOM-based XSS - innerHTML 滥用

**位置**:
- `static/js/notifications_v4.js:22,179,186,215,221,230,235`
- `static/js/bank_data.js:604,608,633,636`
- `static/js/exam_builder_inline_v3.js:264,458,588,590`
- `static/js/user_bank_data_v2.js:304,307,975,979,1385,1390,1497,1502`
- `static/js/public_bank_plaza_v2.js:100,119,163,199,208`

**问题**: 多处使用 `innerHTML` 设置包含用户数据的 HTML，部分未经 `escapeHtml()` 转义。
**影响**: 攻击者可注入恶意脚本。
**修复**: 使用 `textContent` 或确保所有用户数据经过 `escapeHtml()` 处理。

### H-03: 缺少安全 HTTP 头

**位置**: `app/__init__.py`
**问题**: 缺少以下关键安全头：
- `X-Frame-Options: DENY`（防点击劫持）
- `X-Content-Type-Options: nosniff`（防 MIME 嗅探）
- `Strict-Transport-Security`（强制 HTTPS）
- `Content-Security-Policy`（防 XSS）

**修复**: 添加 `@app.after_request` 处理器设置安全头。
