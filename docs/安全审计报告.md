## CRITICAL 严重漏洞

### C-01: 密钥泄露到 Git 历史 `未修复`

**位置**: `.env`
**问题**: 以下敏感凭证已被提交到 Git 历史（commit cd76d88, 6316ea4）：

- `WECHAT_SECRET=714b6315c5e27cb2689c3c1d5bd54e2d`
- `DASHSCOPE_API_KEY=sk-9305b010e9be495b8407611f14394fd5`
- `SECRET_KEY=Saksk1234567890`

**影响**: 任何有仓库访问权限的人可获取所有密钥，伪造 JWT、调用第三方 API。
**修复**:
1. **立即轮换**所有暴露的密钥（微信 Secret、DashScope Key）
2. 使用 `git filter-branch` 或 BFG Repo-Cleaner 从历史中清除
3. 生成强 SECRET_KEY: `python -c "import secrets; print(secrets.token_urlsafe(32))"`
