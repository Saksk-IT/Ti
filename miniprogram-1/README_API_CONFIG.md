# 小程序后端 API / 环境切换说明

本项目已把小程序的后端地址改为“显式模式切换”，避免自动判断环境/IP 带来的混乱：

- **生产模式（默认）**：始终使用 `https://saksk.top/api`
- **自定义模式**：由你在小程序「开发设置」页面手动填写 Host/Port 或完整 URL，并点击“保存并启用自定义”

## 1) 在小程序里切换（推荐）

入口：登录页 →「开发设置」

### 生产模式

- 点击「生产」或「使用生产」
- 生效地址：默认 `https://saksk.top/api`，也可在「开发设置」里改为其它生产/预发地址（并保存为预设）
- 适用：线上/正式环境

### 自定义模式（开发/测试）

点击「自定义」后，有两种填法（二选一）：

1. **Host + Port**
   - Host：电脑局域网 IP（如 `192.168.1.100`）
   - Port：后端端口（默认 `5000`）
2. **完整 URL（含 http/https，可粘贴）**
   - 如 `https://saksk.top/api` 或 `http://192.168.1.100:5000/api`

注意：

- 真机预览无法访问电脑的 `localhost/127.0.0.1`，请使用局域网 IP
- 后端建议启动方式：`python run.py`（监听 `0.0.0.0:5000`）
- 你可以随时切回生产模式；自定义配置会保留（除非点“清除自定义”）

## 2) 微信小程序合法域名配置

生产环境必须配置 HTTPS 合法域名：

1. 登录微信公众平台
2. 「开发」→「开发管理」→「开发设置」→「服务器域名」
3. 在 `request` 合法域名中添加 `https://saksk.top`

本地开发（仅开发者工具）可在「详情」→「本地设置」勾选：

- ✅ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

## 3) 代码层（给开发者）

- 统一入口：`miniprogram-1/miniprogram/utils/config.ts`
- 实际请求以 `config.getApiUrl()` 为准（生产/自定义由 `api_mode_v1` 显式控制）
- 生产地址覆盖：`config.setProdApiUrl()` / `config.clearProdApiUrl()`（存储键：`prod_api_base_url`）
- 生产预设列表：存储键 `prod_api_presets_v1`（仅由「开发设置」页管理）
