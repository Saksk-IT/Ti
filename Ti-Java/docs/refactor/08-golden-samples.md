# 阶段 0 黄金样本说明

## 用途与边界

`golden-samples/` 保存旧 Flask 在固定提交 `700006dfdfa063deb4387be572911e782bcea0d9` 上的最小脱敏 HTTP 契约样本，用于后续 Java 兼容路由的差异比较。它们不是生产数据快照，也不是完整 API 覆盖证明。

捕获过程使用临时 SQLite、测试专用身份和 Flask test client；不访问生产环境或本机持久化业务数据库，不记录 Cookie、Authorization、真实密码或真实用户数据。请求中的测试密码以占位符保存。

## 样本清单

| 文件 | 领域 | 请求 | 基线结果 |
| --- | --- | --- | --- |
| `01-identity.json` | 身份 | `POST /api/login` | HTTP 200 |
| `02-catalog.json` | 题库目录 | `GET /api/public/banks/summary` | HTTP 200 |
| `03-learning.json` | 真实练习写入 | `POST /api/record_result` | HTTP 200；`user_answers` 写入 1 行，正确答案不留错题 |
| `04-assessment.json` | 考试 | `GET /api/exams/records` | HTTP 200 |
| `05-community.json` | 社区 | `GET /api/forum/boards` | HTTP 200 |
| `06-campus.json` | 教务 | `GET /api/edu-schedule/status` | HTTP 200 |
| `07-operations.json` | 后台 | `GET /admin/api/subjects` | HTTP 200 |

`golden-samples/manifest.json` 记录捕获日期、旧提交、隔离方式、脱敏说明和文件清单；当前 `all_success=true`。

## 后续比较规则

兼容测试应先比较 HTTP 方法、路径、状态码、Content-Type、响应信封、字段类型、空值语义、列表/分页结构和稳定业务值，再比较经归一化的正文。不得通过删除字段、忽略整个对象或只断言 HTTP 200 来让测试通过。

以下字段或值属于可预期的运行时变化，应在比较器中以明确、逐字段规则归一化：

- `request_id`、`trace_id`、`correlation_id`：捕获时从黄金正文删除；后续现场对比另行断言这些标识符合格式且非空，不比较具体值。
- 未来补充数据中心样本时，按当前日期生成的学习窗口日期须保留列表长度、顺序、日期格式和相邻天连续性；比较时可将首日平移为固定基准日。当前 7 个样本不含该窗口。
- 时间戳、过期时间和异步任务 ID：出现后只按契约格式与相对关系归一化，不能无条件忽略。
- 无顺序语义的集合：只有仓库契约确认无序时才可按稳定业务键排序；有排序语义的列表必须保持原顺序。

## 尚需扩充的契约维度

这 7 组样本固定基础成功路径；其中练习样本使用固定用户、科目和题目完成一次真实答题写入，其余领域仍以最小/空数据读取为主。阶段 1 及各领域迁移阶段还需在隔离的脱敏非空数据上补充：

- Session、JWT、管理员和匿名身份的权限矩阵；
- 400/401/403/404/409/422/429/500 等错误信封；
- 分页首页/尾页/越界、空值、枚举和精度边界；
- 创建、更新、删除、重复提交与幂等行为；
- 题库权限、考试评分、错题/收藏、论坛互动、消息未读和教务快照等关键不变量；
- 文件上传下载、SSE 事件、后台任务和外部服务失败/重试行为。

扩充样本时必须继续使用测试夹具或脱敏备份副本，并在 manifest 中记录来源提交、隔离环境和归一化规则；不得把真实密钥、Cookie、个人信息或生产响应直接提交到仓库。
