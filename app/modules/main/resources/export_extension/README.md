# SAK 题库导出助手扩展

## 安装方式

1. 解压下载得到的 `SAK题库导出助手扩展.zip`。
2. 在 Chrome / Edge 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `SAK题库导出助手扩展` 文件夹。

## 使用范围

- 学习通作业/考试相关页面会显示“学习通作业导出助手”。
- PTA 题目页面会显示“PTA题目导出”。
- 雨课堂考试结果页会显示“雨课堂题目导出”，并读取当前登录会话下的 `show_paper` 接口数据。

## 一键导入个人题库

1. 先在同一浏览器登录 Ti，并确认能打开“个人题库”页面。
2. 在导出助手中点击“解析题目”。
3. 点击“一键导入题库”，按提示输入目标个人题库 ID。
4. 如本地开发端口不是 `http://localhost:8000`，先在助手里点击“设置站点”修改 Ti 地址。

扩展内置导出所需依赖，安装后不需要再单独安装 Tampermonkey 脚本。
