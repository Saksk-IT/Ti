SAK · 个人题库

个人题库全流程指南

从新建题库 → 导出题目 → 导入题目 → 编辑维护，一次说明白。

0) 先想清楚：你要“按什么维度建库”

推荐命名：科目/章节/来源，例如：计算机网络-第3章-学习通。

1) 新建个人题库

  1. 进入 个人题库，点击「新建题库」。
  2. 填写题库名称与描述（可选），建议把“来源/章节/考试名称”写清楚。
  3. 创建后进入题库详情页，你会看到「题目管理 / 设置 / 分享 / 练习」等入口。

2) 导出题目 → 导入题目（推荐优先 JSON）

学习通 / PTA：优先用脚本导出 JSON 再导入
原因：更稳定、信息更完整；并且能避免 Word 只能识别 A-F（选项超过 6 会丢失）等问题。
  1. 先在学习通 / PTA 页面使用脚本导出 JSON。
  2. 回到本站：进入题库「题目管理」，点击「导入」→「JSON 导入」。
  3. 手工整理题：可用「Word 导入」或「Excel 导入（模板）」。

3) 修改/维护题目（关键：抽查 + 批量修复）

  1. 导入后先抽查 3–5 题：题型、选项、答案、填空空位是否正确。
  2. 在题目管理页用搜索/题型筛选定位异常题；必要时进入编辑页逐题修正。
  3. 需要统一处理时，使用批量选择功能进行「批量设置题型/难度」等操作。

4) 开始练习

  1. 从题库管理页右上角「返回详情」进入练习页面。
  2. 刷题过程中会自动沉淀收藏/错题/做题记录，后续可按这些维度复习。

导入方式怎么选？

推荐顺序
学习通/PTA/爬题：JSON ＞ Word；手工整理：Word ＞ Excel；系统互导：题库包（ZIP）。
JSON（推荐）
稳定、结构化、支持多题型，适合学习通脚本导出。
  • 多选/判断/填空更不易误判。
  • 选项超过 6 个也能导入。
Word（适合手工/排版）
更适合编辑与复习，但有解析规则限制。
  • 选择题仅识别 A-F（最多 6 个选项）。
  • 建议按「Word 导入规则」排版。
Excel（适合批量整理）
按模板填写最稳，适合团队协作与清洗数据。
  • 模板可在导入弹窗内下载。
  • 填空题用 blank_1/blank_2… 列。
题库包（ZIP）
适合在本系统内导出/备份后再导入。
  • 可能包含图片等资源。
  • 用于迁移、备份、分享。

学习通（超星）题目：推荐脚本导出 JSON 导入

一句话原则
要“导入刷题”就用 JSON；要“打印复习”可以导出 Word/PDF。

A. 学习通导出（脚本端）

  1. 打开「资源」页下载 SAK 题库导出助手扩展 并解压。
  2. 在浏览器扩展管理页开启开发者模式，点击“加载已解压的扩展程序”，选择解压后的扩展文件夹。
  3. 打开学习通作业/考试的查看页面，右下角点击脚本按钮 → 「解析本页题目」。
  4. 优先点击「导出 JSON」，得到 *_题库导入.json 文件。

B. 本站导入（SAK 端）

  1. 进入「个人题库」→ 选择题库 → 进入「题目管理」。
  2. 点击「导入」→ 选择「JSON 导入」。
  3. 选择 JSON 文件或直接粘贴 JSON 内容 → 开始导入。
  4. 导入后抽查几题，确认选项/答案/填空空位无误。
常见提醒
  • 选择题选项超过 6：Word 导入会丢失，务必用 JSON。
  • 填空题：题干用 __ 表示空位；答案在 Word 里“空与空用 ; 分隔，同空多答案用 / 或 |”。
  • 少量异常题：导入后在题目管理里逐题编辑即可。

PTA 题目：推荐脚本导出 JSON 导入

一句话原则
要“导入刷题”就用 JSON；Word/PDF 更适合打印复习。

A. PTA 导出（脚本端）

  1. 打开「资源」页下载 SAK 题库导出助手扩展 并解压。
  2. 在浏览器扩展管理页开启开发者模式，点击“加载已解压的扩展程序”，选择解压后的扩展文件夹。
  3. 打开 PTA 题目页（建议先滚动到最底部，确保题目都加载完成）。
  4. 点击右下角「导出」→「解析题目」→ 选择「下载 JSON / 复制 JSON」。

B. 本站导入（SAK 端）

  1. 进入「个人题库」→ 选择题库 → 进入「题目管理」。
  2. 点击「导入」→ 选择「JSON 导入」。
  3. 选择 JSON 文件或直接粘贴 JSON 内容 → 开始导入。
  4. 导入后抽查几题：部分 PTA 页面可能不展示标准答案，导出为空属正常。
常见提醒
  • 题量较多：先滚动到底，避免“虚拟列表/懒加载”导致缺题。
  • 答案不确定：可勾选脚本里的「仅导出答案已确定」，先把题干/选项入库再逐步补答案。
  • 少量异常题：导入后在题目管理里逐题编辑即可。

题目管理页能做什么？

  1. 搜索：支持按题干/答案/解析关键词检索。
  2. 筛选：按题型筛选，配合每页数量更快定位问题。
  3. 导入/导出：支持 Word / JSON / Excel / 题库包。
  4. 编辑：点击题目进入编辑页，修改题干/选项/答案/解析/难度。
  5. 批量：勾选题目后可进行批量设置与批量导出（适合统一修复）。
导入后推荐的“抽查动作”
  1. 随机打开 3 道选择题：答案字母是否对应正确选项。
  2. 随机打开 2 道填空题：题干空位数量是否匹配，答案是否被正确分空。
  3. 如果发现“选项被打散/答案格式不对”：优先改用 JSON 导入或回到 Word 导入页做微调。

Word 导入解析规则（核心）

Word 导入是“按文本规则解析”，排版符合规则才能稳定识别。
最小可用格式示例 
1. TCP 三次握手的目的是什么？
A. 建立连接
B. 断开连接
答案：A
解析：……（可选）

2. 判断题示例
答案：正确

3. 填空题示例：HTTP 的默认端口是 __ 。
答案：80
  • 题号：每题以 1. 或 1、 开头。
  • 选项：以 A./A、… 开头（最多识别到 F）。
  • 答案行：以「答案：/正确答案：/参考答案：」开头（中英文冒号都可）。
  • 解析行：以「解析：/分析：/详解：」等开头（可选）。
  • 填空题空位：下划线或括号会被识别为 __；多空答案用 ; 分隔（同一空多答案用 / 或 |）。
学习通用户的最佳实践
脚本导出的 Word 已按规则排版，但若出现选项超过 6、题型复杂等情况，请直接导出 JSON 导入。
