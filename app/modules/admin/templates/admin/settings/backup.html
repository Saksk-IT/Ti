Cloudflare R2 配置教程

  1. 在 Cloudflare R2 中创建私有 Bucket，禁止公开访问。
  2. 进入 Manage API Tokens，创建仅具备 Object Read & Write 权限的令牌。
  3. 资源范围选择仅指定 Bucket，不要授予账户级的其他权限。
  4. 立即复制只显示一次的一次性 Secret，同时保存 Access Key ID。
  5. 复制 Bucket 的 S3 API Endpoint，Region 保持 auto。
  6. 回到本页填写信息，先保存，再点击测试连接。
查看 Cloudflare R2 官方文档
