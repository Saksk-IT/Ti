微信小程序配置

配置小程序微信登录、Web 扫码登录与小程序码生成所需的 AppID、AppSecret 和运行参数。未填写后台配置时继续使用环境变量兜底。

小程序凭据

用于小程序微信登录与扫码登录确认，应与微信开发者工具项目 AppID 一致。
已配置时会显示为脱敏值；保持脱敏值不变不会覆盖原密钥。

扫码登录小程序码

自动模式会在调试环境使用开发版，非调试环境使用正式版。
开发版/体验版常因页面未提审导致校验失败，自动模式会按版本选择。

生效范围

小程序微信登录接口会优先读取这里保存的 AppID 和 AppSecret。
Web 端扫码登录的小程序码生成也会复用同一套配置。
配置为空时，系统继续读取 Docker 环境变量中的 WECHAT_APPID / WECHAT_SECRET。
